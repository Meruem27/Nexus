## What is Nexus?

Nexus is a simple, fast, Markdown-first personal blog and knowledge base.

No admin panel is required. Add a `.md` file to `docs/`, push it to GitHub, and the site will build and publish it automatically.

## Design principles

- The light theme uses a soft gray-white background for comfortable reading.
- The dark theme uses restrained charcoal layers instead of harsh pure black.
- The interface keeps only essential interactions, with no large gradients or heavy animations.
- Mermaid, syntax highlighting, a table of contents, tags, archives, and site search are supported.
