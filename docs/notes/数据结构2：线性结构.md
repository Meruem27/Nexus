# 1 数组

## 1.1 一维数组与二维数组

**定义：**数组是一种**连续存储结构**，通过下标进行随机访问。

**特点：**

- 随机访问
- 连续内存
- 固定大小

## 1.2 动态数组

**扩容机制：**

1. 扩容策略：
   - Java ArrayList：1.5倍扩容
   - C++ vector：2倍扩容
   - Python list：1.125倍扩容 + 常数
2. 扩容过程：
   - 分配新的更大的连续内存空间
   - 将旧数组元素逐个复制到新数组
   - 释放旧数组内存
   - 更新指针指向新数组

## 1.3 时间复杂度

| 操作        | 时间复杂度 |
| :---------- | :--------- |
| 访问 arr[i] | O(1)       |
| 查找元素    | O(n)       |
| 头部插入    | O(n)       |
| 尾部插入    | O(1)       |
| 删除元素    | O(n)       |
| 排序        | O(nlogn)   |

## 1.4 面试技巧

### 1.4.1 双指针

**适用场景：**

- 有序数组
- 子数组问题
- 快慢移动
- 两段收缩

**常见形式：**

1. **左右指针**

   - 模板

     ```c++
     int left = 0;
     int right = nums.size()-1;
     
     while(left < right)
     {
         if(condition)
             left++;
         else
             right--;
     }
     ```

   - 典型题目：

     - [两数之和](https://leetcode.cn/problems/two-sum/)

       ```c++
       class Solution {
       public:
           vector<int> twoSum(vector<int>& nums, int target) {
               // 建立一个数组作为结果输出
               vector<int> res;
               
               // 将数组下标与数值建立二元组，避免排序后下标乱序
               vector<pair<int,int>> index_nums;
               for(int i=0; i<=nums.size()-1; i++)
               {
                   pair<int,int> p = {nums[i],i};
                   index_nums.push_back(p);
               }
       
               // 排序
               sort(index_nums.begin(),index_nums.end());
       
               // 左右指针
               int left = 0;
               int right = nums.size() - 1;
               while(left < right)
               {
                   if(index_nums[left].first + index_nums[right].first < target)
                   {
                       left++;
                   }
                   else if(index_nums[left].first + index_nums[right].first > target)
                   {
                       right--;
                   }
                   else
                   {
                       res.push_back(index_nums[left].second);
                       res.push_back(index_nums[right].second);
                       break;
                   }
               }
       
               return res;
           }
       };
       ```

     - [三数之和](https://leetcode.cn/problems/3sum/)

       ```c++
       class Solution {
       public:
           vector<vector<int>> threeSum(vector<int>& nums) {
               // 建立一个数组作为结果输出
               vector<vector<int>> res;
       
               // 自动去重和排序
               sort(nums.begin(),nums.end());
       
               // 左右指针
               for(int i=0; i<=static_cast<int>(nums.size())-3; i++)
               {
                   int left = i+1;
                   int right = nums.size()-1;
       
                   // 索引i去重
                   if(i > 0 && nums[i] == nums[i - 1])
                       continue;
       
                   while(left<right)
                   {
                       if(nums[i] + nums[left] + nums[right] < 0)
                       {
                           left++;
                       }
                       else if(nums[i] + nums[left] + nums[right] > 0)
                       {
                           right--;
                       }
                       else
                       {
                           res.push_back({nums[i], nums[left], nums[right]});
                           
                           // 索引left和right去重
                           while(left<right && nums[left]==nums[left+1])
                           {
                               left++;
                           }
                           while(left<right && nums[right]==nums[right-1])
                           {
                               right--;
                           }
                           left++;
                           right--;
                       }
                   }
               }
       
               return res;
           }
       };
       ```

     - [盛最多水的容器](https://leetcode.cn/problems/container-with-most-water/)

       ```c++
       class Solution {
       public:
           int maxArea(vector<int>& height) {
               // 最大面积
               int max_area = INT_MIN;
       
       
               // 左右指针
               int left = 0;
               int right = height.size()-1;
               while(left < right)
               {
                   int area = (right - left) * min(height[left],height[right]);
                   max_area = max(max_area,area);
       
                   if(height[left] < height[right])
                   {
                       left++;
                   }
                   else
                   {
                       right--;
                   }
               }
       
               return max_area;
           }
       };
       ```
