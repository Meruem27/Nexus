# 1 数组

## 1.1 一维数组与二维数组

**定义：**数组是一种**连续存储结构**，通过下标进行随机访问。

**特点：**

- 随机访问
- 连续内存
- 固定大小

## 1.2 动态数组

**扩容机制：**

1. 扩容策略：
   - Java ArrayList：1.5倍扩容
   - C++ vector：2倍扩容
   - Python list：1.125倍扩容 + 常数
2. 扩容过程：
   - 分配新的更大的连续内存空间
   - 将旧数组元素逐个复制到新数组
   - 释放旧数组内存
   - 更新指针指向新数组

## 1.3 时间复杂度

| 操作        | 时间复杂度 |
| :---------- | :--------- |
| 访问 arr[i] | O(1)       |
| 查找元素    | O(n)       |
| 头部插入    | O(n)       |
| 尾部插入    | O(1)       |
| 删除元素    | O(n)       |
| 排序        | O(nlogn)   |

## 1.4 面试技巧

### 1.4.1 双指针

**适用场景：**

- 有序数组
- 子数组问题
- 快慢移动
- 两段收缩

**常见形式：**

1. **左右指针**

   - 模板

     ```c++
     int left = 0;
     int right = nums.size()-1;
     
     while(left < right)
     {
         if(condition)
             left++;
         else
             right--;
     }
     ```

   - 典型题目：
     - 两数之和
     - 三数之和
     - 盛最多水的容器
     - 删除有序数组重复元素
