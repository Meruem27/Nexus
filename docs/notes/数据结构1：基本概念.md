# 1 三要素

1. 逻辑结构
   - 集合结构：元素之间毫无关系
   - 线性结构：一对一
   - 树形结构：一对多
   - 图形结构：多对多
2. 存储结构
   - 顺序存储：内存空间连续，支持随机访问
   - 链式存储：内存空间动态分配
   - 索引存储：建立附件索引表
   - 散列存储/哈希存储：根据关键字计算存储地址
3. 数据运算

# 2 时间复杂度

常见时间复杂度：
$$
O(1) < O(log n) < O(n) < O(n log n) < O(n^2) < O(n^3) < O(2^n) < O(n!) < O(n^n)
$$

# 3 空间复杂度

常见空间复杂度：只分析辅助变量所占空间

- $O(1)$：原地算法，只用常数级额外空间
- $O(log n)$：递归栈深度
- $O(n)$：一维辅助数组
- $O(n^2)$：二维辅助数组
